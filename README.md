# ProtoDUNE Analysis

ProtoDUNE-SP is an 800-tonne liquid argon detector at CERN, built as a 
full-scale prototype for the DUNE experiment. It images particle 
interactions in 3D by recording the trails of charge and light left 
behind as particles traverse the liquid argon.

<img src="https://raw.githubusercontent.com/vikasnt/vikasnt/main/protodune_event.png" width="600px">



This repository contains analysis code for two studies using pion beam data:

**1. Neutral pion reconstruction**
Reconstructing photon pair signatures from neutral pion decays in 3D 
detector images, used to calibrate electromagnetic shower reconstruction 
and validate detector energy response.

**2. Pion production cross-section**
First measurement of the pion production channel in liquid argon — 
a key systematic input for neutrino energy reconstruction in DUNE.
